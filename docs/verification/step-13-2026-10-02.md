## Learning check
1. **Why does testing `PositionClaimFilter.filter()` in isolation (no evidence, no facts) make sense for finding both the fix's effectiveness and its false positives?** `PositionClaimFilter` is a pure text-pattern filter - it takes only the model's answer text, with no access to FACTS or CONTEXT. So any sentence it removes or keeps is a fact about the patterns alone, independent of what evidence a particular company's report happens to contain. This made it straightforward to confirm both that the six new sentences are now caught, and that a legitimate sentence with no real peer intent is caught too - with no need to spin up a full report each time.
2. **Why is "peer figure reaches the reader with no attribution" now effectively impossible, even though the model is never shown a filter that specifically recognises every wording?** Because the model is never given a peer figure to restate at all (`ContextRenderer.renderForModel` replaces every peer line with `PEERS_OMITTED_NOTE`). A precise (decimal) restatement is therefore always absent from evidence, so `NumericClaimVerifier`'s ungrounded-figure check removes it regardless of wording. Only a coarse, unit-bearing, no-decimal restatement needed a second, dedicated check (this run's `FIGURE_WITH_UNIT` + `GROUP_MENTION`), because that specific pattern can coincidentally exact-match an unrelated bare integer already in the long FACTS text.
3. **Why doesn't the false positive found this run break any invariant, even though it deletes a true, sourced sentence from the report?** No invariant requires the model's interpretation text to be complete or maximal - only that nothing false, ungrounded, or judgement-laden reaches the reader (INV-3, INV-5, INV-7 and S13-5/S13-6 all police what must NOT appear). An over-cautious removal subtracts true content but adds nothing false; the removal is disclosed in a footnote, consistent with how `NumericClaimVerifier` and `UnsupportedClaimFilter` already behave when they remove a defensible sentence out of caution.
